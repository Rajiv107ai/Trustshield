### 2.3 Mathematical Proof of Zero In-Sample Calibration Error
The result $0.0000$ is **mathematically expected** when evaluating 1D Isotonic Regression in-sample:
1. `IsotonicRegression` solves the weighted least-squares problem $\min \sum_i (y_i - \hat{p}_i)^2$ subject to $\hat{p}_i \le \hat{p}_j$ for $s_i \le s_j$ using the Pool Adjacent Violators (PAV) algorithm.
2. The PAV algorithm partitions the input scores into piecewise constant blocks $B_k$. Within each block $B_k$, the output probability is defined explicitly as the empirical mean of the true labels:
   $$\hat{p}_i = \frac{1}{|B_k|} \sum_{j \in B_k} y_j \quad \forall i \in B_k$$
3. Therefore, within any block or collection of non-overlapping blocks spanning a bin, the sample average of the predicted probabilities equals the sample average of the ground truth labels:
   $$\sum_{i \in \text{bin}} \hat{p}_i = \sum_{i \in \text{bin}} y_i \implies \frac{1}{|\text{bin}|}\sum_{i \in \text{bin}}\hat{p}_i = \frac{1}{|\text{bin}|}\sum_{i \in \text{bin}} y_i$$
4. Consequently, $| \text{mean\_confidence} - \text{mean\_accuracy} | \equiv 0$ for every bin. The floating-point residual ($3.07 \times 10^{-18}$) is IEEE-754 double-precision numerical noise.

**Proof of Temporal Isolation:**
- For any transaction occurring in month $i$ (e.g. `2024-05-15`), the feature assignment via `attach_snapshot_features` looks up `snapshots[months[i]]`.
- `snapshots[months[i]]` was constructed using `cutoff = months[i-1]` (e.g. `2024-04-01`).

- Therefore, **zero** orders from month $i$ and **zero** future orders are visible to the graph construction. No same-month edges, no same-month degree increments, and no future PageRank propagation can occur.

- Setting `allow_exact_matches=False` strictly guarantees that return events occurring on or after the exact transaction millisecond cannot increment `buyer_returns_before`.
